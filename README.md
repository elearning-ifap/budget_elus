# Formation « Comprendre et piloter le budget »

Version autonome GitHub Pages — V8 lot 3.2, correctif mission 5.

## Mise en ligne

1. Déposer l’ensemble des fichiers et dossiers à la racine du dépôt GitHub.
2. Dans **Settings → Pages**, sélectionner **Deploy from a branch**.
3. Choisir la branche `main` et le dossier `/ (root)`.
4. Enregistrer, puis ouvrir l’adresse fournie par GitHub Pages.

Le fichier `index.html` doit rester à la racine. Les dossiers `media` et `resources` ne doivent pas être renommés.

## Contenu

- `index.html` : formation ;
- `app.js` : logique pédagogique ;
- `media/` : illustrations ;
- `resources/` : fiches PDF téléchargeables ;
- `.nojekyll` : publication statique sans transformation Jekyll.
